# ServiceNow Workflow Library

A reference collection of ServiceNow workflow examples retained for learning, design comparison, and legacy-platform support.

## Purpose

This repository provides examples of workflow automation patterns from the classic ServiceNow Workflow Editor era. It is useful when maintaining older implementations, understanding historical automation design, or planning migration to modern Flow Designer patterns.

## Use this repository for

- Reviewing legacy workflow structures and activities.
- Understanding automation patterns in older ServiceNow applications.
- Comparing classic Workflow Editor implementations with Flow Designer.
- Supporting migration and refactoring discussions.

## Important platform note

For new ServiceNow development, Flow Designer and modern IntegrationHub capabilities are generally preferred where they meet the requirement. Existing workflows should be assessed before migration because behaviour, approvals, scripts, and integrations may not map one-to-one.

## Repository context

This project originated from the ServiceNow Innovation Library ecosystem and is retained here as a technical reference. Review original source history and licensing before redistributing or republishing individual assets.
